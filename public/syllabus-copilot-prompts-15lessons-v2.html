1. 概要

本資料は、「プログラミング中級（HTML/CSS/JavaScript）」のシラバス全15回に対応した、GitHub Copilot Chat用プロンプトのバリエーション集です。各回につき**3種類（教員実演用 / 学生演習用 / 発展・対話型デバッグ用）**の具体例を提示しています。

指導上の共通ポイント

  • 曖昧な指示（「良い感じにして」等）ではなく、構造・条件・制約を明確に与えるプロンプト思考を養います。
  • AIが生成したコードに対して、ブラウザのデベロッパーツール（F12）や Copilot Chat への解説要求（Read & Verify）を組み合わせます。

—

2. 第1回：インターネットと Web の基本を理解する

2.1. ねらい

Webの仕組み（クライアント/サーバー通信）とフロントエンド（HTML/CSS/JS）の役割、AIペアプログラミング環境の全体像を理解する。

2.2. プロンプト例

2.2.1. 例1（教員実演：概念解説要求）

WebブラウザがWebサーバーからHTML、CSS、JavaScriptを受け取って画面を表示する仕組みについて、プログラミング初心者向けに3つのステップで分かりやすく解説してください。

2.2.2. 例2（学生演習：比喩を用いた理解補助）

HTML（構造）、CSS（見た目）、JavaScript（動作）の3つの役割の違いを、家づくり（建築・内装・設備）の例えを使って分かりやすく説明してください。

2.2.3. 例3（発展：開発ツールの連携理解）

VS Code、GitHub Codespaces、GitHub Copilotの3つが、開発現場でどのように連携して使われているかを箇条書きで簡潔にまとめてください。

2.3. 指導解説ポイント

  • 生成された解説テキストを読み合わせ、Webの基本構造を把握させます。

—

3. 第2回：HTML の基本を理解してコーディングする

3.1. ねらい

HTMLの基本タグ（h1〜h6, p, ul, li, a等）と、ページのセマンティック構造（header, main, footer）を理解する。

3.2. プロンプト例

3.2.1. 例1（教員実演：自己紹介ページの骨格）

初心者向けの自己紹介ページのHTML構造を作成してください。header, main, footer タグを使い、h1に見出し『山田太郎のポートフォリオ』、pに挨拶文、ulに趣味を3つ配置してください。CSSやJavaScriptは含めず、純粋なHTMLだけにしてください。

3.2.2. 例2（学生演習：イベント告知ページ）

大学の大学祭イベント告知ページのHTMLを作成してください。h1にイベント名、pに日時と場所、ol要素を使ってタイムスケジュールを3つ、ul要素で注意事項を2つ記述してください。スタイリングは不要です。

3.2.3. 例3（発展：カード型コンテンツの骨格）

Webサイトに掲載する『おすすめ本紹介カード』のHTMLを作成してください。h2に書籍タイトル、pに著者名と短いあらすじ、ulに特徴タグ（3つ）、a要素で購入リンクのダミーを配置してください。

3.3. 指導解説ポイント

  • CSSを含めない純粋なHTMLタグの役割とDOMツリーの親子関係をF12ツールで確認させます。

—

4. 第3回：HTML の基本を理解してコーディングする。その2

4.1. ねらい

表データ（table）や入力フォーム（form, input, select, button）、メディア要素のタグ構造を理解する。

4.2. プロンプト例

4.2.1. 例1（教員実演：履歴書テーブルと問い合わせフォーム）

先ほど作成したHTMLの main 要素内に、学歴を表示する table 要素（年・学校名の2列）と、お問合せ用の form 要素（名前入力、メールアドレス入力、お問い合わせ内容のtextarea、送信ボタン）を追加してください。

4.2.2. 例2（学生演習：アンケートフォームと料金比較表）

Webサービスの利用アンケートフォームを作成してください。ラジオボタンで満足度（3段階）、チェックボックスで利用頻度の高い機能（3つ）、ドロップダウン（select）で年代を選択できるようにしてください。また、下にプラン別料金表（table）を配置してください。

4.2.3. 例3（発展：ログイン画面とマルチメディア）

ユーザーログイン画面のHTMLを作成してください。ユーザーID（text）、パスワード（password）、ログイン保持（checkbox）、ログインボタンを配置してください。また、ページ上部にサービスロゴ用の img タグと、ダミーの audio 要素を追加してください。

4.3. 指導解説ポイント

  • フォームの `type` 属性による入力形式の違いや、`table` の `tr`, `th`, `td` の入れ子構造を解説します。

5. 第4回：CSS の基本を理解する

5.1. ねらい

CSSセレクタ、カラーコード、フォント、余白（margin/padding）によるデザイン（Vibe）表現の基礎を理解する。

5.2. プロンプト例

5.2.1. 例1（教員実演：和風モダンデザイン）

このHTMLにCSSを追加してください。デザインの雰囲気（Vibe）は『シンプルで清潔感のあるモダンな和風』にし、メインカラーを紺色（#1B2A4A）、背景色を生成り色（#F7F6F2）にし、カード風の枠線と余白（margin/padding）を整えてください。styleタグ内に記述してください。

5.2.2. 例2（学生演習：ポップ＆カジュアルデザイン）

既存のHTMLに対して、明るくポップな印象を与えるCSSを適用してください。アクセントカラーにオレンジ色（#FF8C00）、角丸（border-radius: 12px）、ボタンにほんのり影（box-shadow）を付けて、見出しのフォントサイズを大きくしてください。

5.2.3. 例3（発展：ダークモードスタイル）

既存のHTMLをダークテーマ風にスタイリングしてください。背景色をダークグレー（#1E1E1E）、文字色をオフホワイト（#E0E0E0）、見出しの差し色にネオンブルー（#00E5FF）を使い、全体的にモダンでクールな印象にしてください。

5.3. 指導解説ポイント

  • 抽象的な「Vibe（雰囲気）」の言葉が、具体的なCSSプロパティやカラーコードにどう変換されるかを観察させます。

—

6. 第5回：CSS の基本を理解する。その2

6.1. ねらい

FlexboxやCSS Gridを用いたレイアウト構築と、メディアクエリ（@media）によるレスポンシブデザインを理解する。

6.2. プロンプト例

6.2.1. 例1（教員実演：Flexbox 3列カードとレスポンシブ）

Flexbox を使って、3つの自己紹介カード要素をPC表示で横並びに配置してください。さらに、画面幅が768px以下のスマホ表示のときは縦並び（1列）に自動で切り替わるよう、メディアクエリ（@media）を追加してください。

6.2.2. 例2（学生演習：CSS Grid によるダッシュボード配置）

CSS Grid を使って、Webページのレイアウトを作成してください。ヘッダー（全幅）、左サイドバー（幅200px）、メインコンテンツ（残り幅）、フッター（全幅）の配置をGridプロパティで整えてください。

6.2.3. 例3（発展：レスポンシブナビゲーションバー）

ヘッダー内のナビゲーションメニュー（ul, li）を Flexbox で横並びに配置し、右寄せにしてください。モバイル画面（600px以下）のときはメニュー項目を非表示にして縦並びにするレスポンシブスタイルを作成してください。

6.3. 指導解説ポイント

  • ブラウザのウィンドウサイズを変更し、レスポンシブ表示の変化をデベロッパーツールで確認させます。

7. 第6回：CSS の応用（CMS、Bootstrap など）

7.1. ねらい

外部UIライブラリ（Bootstrap 5等）のCDN導入と、既存コンポーネントを活用した効率的な画面装飾を理解する。

7.2. プロンプト例

7.2.1. 例1（教員実演：Bootstrap 5 の導入と全体装飾）

Bootstrap 5 をCDN経由で読み込み、全体のデザインをBootstrapのコンポーネント（Navbar, Heroセクション, Card, Primary Button）を使ったスタイリッシュなビジネス風Webサイトに作り直してください。

7.2.2. 例2（学生演習：Bootstrap Grid システムの活用）

Bootstrap 5 のグリッドシステム（container, row, col-md-4）を使って、商品カードをPCでは3列、タブレットでは2列、スマホでは1列に自動配置するHTML構造とクラスを作成してください。

7.2.3. 例3（発展：モーダルダイアログとバッジ機能の追加）

Bootstrap 5 のコンポーネントを使い、ボタンを押すと出現する『利用規約表示用モーダル（Modal）』と、カード右上に付く『NEW』バッジ（Badge）を追加してください。

7.3. 指導解説ポイント

  • ゼロからCSSを書く場合と、ライブラリを使用する場合の生産性・柔軟性の違いを考察させます。

8. 第7回：JavaScript イントロダクション

8.1. ねらい

JavaScriptの役割（動的処理）を理解し、スクリプトの読み込み、ボタンイベント、コンソール出力（console.log）の基本を学ぶ。

8.2. プロンプト例

8.2.1. 例1（教員実演：コンソール出力とイベントListener）

HTML内のボタンをクリックした際に、ブラウザのデベロッパーコンソール（console.log）に『Hello, JavaScript!』とメッセージを出力する一番シンプルなJavaScriptコードを作成してください。

8.2.2. 例2（学生演習：アラート表示とテキスト変更）

ボタンをクリックすると、『登録が完了しました』というアラートダイアログ（alert）を表示し、さらに指定したpタグの文字を『手続き済み』に変更するJavaScriptを作成してください。

8.2.3. 例3（発展：外部JSファイルの分離とdefer属性）

JavaScriptコードを外部ファイル `app.js` に切り出し、HTMLの head 要素内で `defer` 属性を付けて安全に読み込む構造を作成してください。DOMの読み込み完了時にコンソールログを出力させてください。

8.3. 指導解説ポイント

  • F12の「コンソール（Console）」タブを開き、スクリプトのログやエラーがどのように出力されるかを実演します。

9. 第8回：基本的な書き方を身に着ける

9.1. ねらい

変数（let / const）、データ型（数値、文字列、Boolean）、テンプレートリテラルの扱いをマスターする。

9.2. プロンプト例

9.2.1. 例1（教員実演：変数定義とテンプレートリテラル）

ユーザーの『名前（文字列）』『年齢（数値）』『学生かどうか（Boolean）』を宣言する変数を定義し、それらを組み合わせて『〇〇さん（〇歳）の自己紹介』という文章をテンプレートリテラル（` `）で作成して画面に表示してください。

9.2.2. 例2（学生演習：型チェックと明示的型変換）

inputタグから取得した文字列表型の数値『100』と『200』を、Number()関数で数値型に変換してから足し算し、その結果と型名（typeof演算子）をコンソールに出力する処理を書いてください。

9.2.3. 例3（発展：constとletの使い分け）

定数（const）として消費税率（0.1）を定義し、変数（let）として商品小計を定義します。再代入を行って合計金額を計算するプログラムを作成し、constに誤って再代入しようとした際のエラーを観察してください。

9.3. 指導解説ポイント

  • `let` と `const` の再代入可否の違いや、文字列連結（`+`）と数値加算の挙動差を解説します。

10. 第9回：演算子を理解し、使用する

10.1. ねらい

算術演算子、比較演算子（厳密等価 `===`）、論理演算子（`&&`, `||`, `!`）、三項演算子の使い方を理解する。

10.2. プロンプト例

10.2.1. 例1（教員実演：割引計算と複合条件判定）

商品の『定価』と『割引率』から割引後の価格を計算し、さらに『購入金額が5,000円以上かつ会員（isMember === true）である場合に送料無料』という判定結果（True/False）を計算して画面に出力する処理を作成してください。

10.2.2. 例2（学生演習：割り勘計算とあまりの算出）

飲み会の『合計金額』と『参加人数』の変数を定義し、1人あたりの支払額（割り算 `/` ）と、端数・あまり（あまり演算子 `%` ）を計算して画面に分かりやすく表示するJavaScriptを書出してください。

10.2.3. 例3（発展：三項演算子による条件表示）

年齢（age）変数を受け取り、三項演算子 `(age >= 18 ? "大人料金: 1,800円" : "子供料金: 1,000円")` を使って、1行でメッセージを判定・表示する処理を作成してください。

10.3. 指導解説ポイント

  • `=`（代入）と `===`（厳密比較）の違いや、複合論理条件の組み立て方を解説します。

—

11. 第10回：制御構文を理解し、使用する

11.1. ねらい

条件分岐（if-else, switch）と繰り返し処理（for, while）によるロジックの構築を理解する。

11.2. プロンプト例

11.2.1. 例1（教員実演：配列ループとifによる成績判定）
