2. 2. 授業概要・到達目標

2.1. 授業概要

この授業では、アプリケーション開発における、主にフロントエンド側の技術を学ぶ。フロントエンドとは、ユーザが情報を閲覧したり操作したりするために直接利用する、アプリケーションの画面を構成する要素である。画面を作成するために広く用いられるマークアップ言語(HTML/CSS 等)と、ユーザの操作に応じてイベントを処理するスクリプト言語(JavaScript/TypeScript 等)について実践的に理解する。

2.2. 授業到達目標及びテーマ

以下3点を到達目標とする。

  1. フロントエンドの技術を理解し利用できる。
  2. マークアップ言語を理解し、見やすい画面を表現できる。
  3. JavaScript を理解し、動的なユーザインタフェースを実現できる。

3. 3. 授業計画（全15回）

各回ともに、準備・事後学習として「教科書の対象部分の事前学習と事後学習(課題含む)」が240分想定されています。

  1. インターネットと Web の基本を理解する。
  2. HTML の基本を理解してコーディングする。
  3. HTML の基本を理解してコーディングする。その2。
  4. CSS の基本を理解する。
  5. CSS の基本を理解する。その2。
  6. CSS の応用(CMS、Bootstrap など)
  7. JavaScript イントロダクション
  8. 基本的な書き方を身に着ける。
  9. 演算子を理解し、使用する。
  10. 制御構文を理解し、使用する。
  11. 組み込みオブジェクトを理解し、使用する。
  12. 関数を理解し利用する。
  13. オブジェクト指向構文
  14. DOM(Document Object Model)
  15. 高度なクライアントサイド開発
