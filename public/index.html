1. はじめに

本サイトは、2026年度後期に開講される「プログラミング中級（DI1A）」の授業資料・演習ガイド・課題提出情報を集約したポータルページです [70]。本授業では、Webアプリケーションのフロントエンド（画面構成・動的機能）を支える HTML / CSS / JavaScript の実践的な習得を目指します [70, 71]。

今年度の授業では、最新のAI支援開発ツール GitHub Copilot を活用し、AIと対話しながらコードを生成・理解・デバッグする バイブコーディング（Vibe Coding） の学習スタイルを取り入れます [15, 58]。

3. 授業到達目標

  1. フロントエンドの技術（Webの仕組み・クライアント/サーバー通信）を理解し利用できる [70]。
  2. マークアップ言語（HTML/CSS）を理解し、見やすく使いやすい画面を表現できる [70]。
  3. JavaScript を理解し、動的なユーザーインタフェースを実現できる [70]。

5. 授業計画（全15回スケジュール）

回 授業テーマ 主な学習内容・GitHub Copilot活用アプローチ
第1回 GitHub開発環境の構築と準備 アカウント作成、学割申請、授業Organization参加、Codespaces/Copilot起動確認 [59, 81]
第2回 HTML の基本を理解してコーディングする タグ構造（h1, p, ul）とセマンティックタグ（header, main, footer）の骨格作成 [60, 71]
第3回 HTML の基本を理解してコーディングする。その2 フォーム要素（form）やテーブル（table）構造の追加と拡張 [71]
第4回 CSS の基本を理解する 色、余白、配置の基礎と「Vibe（雰囲気）」を指定したスタイリング [60, 71]
第5回 CSS の基本を理解する。その2 Flexboxレイアウトおよびメディアクエリ（@media）によるレスポンシブ対応 [71]
第6回 CSS の応用(CMS、Bootstrap など) Bootstrap 5 等の外部UIライブラリを活用したデザイン刷新 [71]
第7回 JavaScript イントロダクション スクリプトの読み込みとコンソール（console.log）出力の理解 [71]
第8回 基本的な書き方を身に着ける 変数宣言（let / const）とデータ型の扱い [71]
第9回 演算子を理解し、使用する 算術・比較・論理演算子の活用と判定処理 [71]
第10回 制御構文を理解し、使用する 条件分岐（if）および繰り返し処理（for / while） [71]
第11回 組み込みオブジェクトを理解し、使用する Date や Math.random など組み込みオブジェクトの操作 [71]
第12回 関数を理解し利用する 関数の定義、引数・戻り値、アロー関数の理解 [71]
第13回 オブジェクト指向構文 クラス（class）、プロパティ、メソッドの定義と利用 [71]
第14回 DOM(Document Object Model) DOM操作とイベントハンドリング（classList.toggle 等による動的切替） [61, 71]
第15回 高度なクライアントサイド開発 API連携（fetch / async/await）、非同期処理、try-catchデバッグ [61, 71]
