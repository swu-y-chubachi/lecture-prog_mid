* GitHubアカウント作成とOrganization参加
1. **GitHubアカウントの登録**: 大学発行のメールアドレス（）を使用してアカウントを作成または追加認証する。
2. **GitHub Education（学割）申請**: 学生証画像を準備し、GitHub Student Developer Pack へ申請を行う（GitHub Copilot と Codespaces 月180時間が無料化）。
3. **アカウント、GitHub URLの提出**: プロフィール名（英字本名）を設定の上、URLを提出する。
4. **Organizationへの参加**: 招待メールまたはリンクを開き、授業チームへ参加する。
