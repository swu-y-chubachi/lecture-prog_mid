* GitHubアカウント作成とOrganization参加
本授業（プログラミング中級）を受講するために必要なクラウド基盤である *GitHub アカウントの作成* 、 *GitHub Education（学割）への申請* 、 *プロフィールURLの提出* 、および *授業用 Organization への参加手順* を解説します。

---

** GitHub Education のアカウントを作成する
本授業では GitHub Copilot や GitHub Codespaces などの最新AI開発ツールを全額無料で利用するため、GitHub Education（Student Developer Pack）の学割申請を行います。

*** GitHub アカウントの作成
- STEP 1: GitHub 公式サイトにアクセス
  - ブラウザで GitHub公式サイト（https://github.com/） にアクセスします。
  - 画面右上にある 「Sign up」（または「Get started」）をクリックします。
- STEP 2: サインアップ（登録方法の選択）
  - 登録画面にある 「Continue with Google」（Googleで継続）をクリックします。
  - アカウント選択画面が表示されたら、大学のGoogleアカウントを選択してログインします。
  - ユーザー名（Username）の設定画面が表示されたら、 *ユーザー名（Username）を *swu-学籍番号（例: ~swu-12345678~ ）* に設定します。
      - 既存アカウントを流用していてユーザー名の変更が難しい場合は、担当教員に相談してください。
- STEP 3: 本人確認（キャプチャ認証）
  - 画面に「Verify your account」（人間であることの確認）が表示されます。
  - 画面の指示に従ってパズルや画像の選択（ロボット認証）をクリアし、「Create account」 をクリックします。
- STEP 4: メールアドレスの認証（コード入力）
  - 大学のGoogleメール（Gmail）の受信トレイを確認します。
  - GitHubから 8桁の認証コード（Launch code） が届いているので、画面の入力欄に入力します。

- STEP 5: 初期設定（アンケート）
  - アンケート画面が表示されます（スキップしても差し支えありません）。
    - チーム人数の選択: 「Just me」
    - 立場の選択: 「Student」
    - 興味のあるテーマの選択画面が表示されたら、そのまま下部へスクロールします。
    - プラン選択画面で 「Continue for free」（無料プラン）を選択します。

ダッシュボード画面が表示されたら、基本登録は完了です。

*** COMMENT 既にアカウントがある場合
1. ブラウザで [[https://github.com/][GitHub 公式サイト]] にアクセスして Sign-in します。
2. 右上のアイコンから ~Settings~ > ~Emails~ を開きます。
3. 大学から付与されたメールアドレス（ ~27xxxxxx@st.swu.ac.jp ）を入力して ~Add~ をクリックします。
4. 大学メールの受信箱に届く認証メール（Verification email）内のリンクをクリックし、アドレスの所有確認（Verified）を完了させます。
5. ~Settings~ > ~Account~ を開き、

*** プロフィール氏名（ローマ字本名）の設定
学割審査時の本人確認エラーを防ぐため、プロフィール表示名を *学生証に記載されている英語表記* に設定します。
1. ~Settings~ > ~Public profile~ を開きます。
2. ~Name~ 欄に *英語表記の本名（例: Hanako SHOWA）* を入力して ~Update profile~ をクリックします。

*** GitHub Education（学割）の申請手順
1. [[https://education.github.com/discount_requests/student_application][GitHub Education 申請ページ]] にアクセスします。
2. 学割対象として登録した大学メールアドレス（ ~27xxxxxx@st.swu.ac.jp~ ）を選択します。
3. 学校名（大学名）を入力・選択します。
4. *位置情報（GPS）の許可*: ブラウザやスマホの位置情報アクセス権限を「許可」にします（学内または自宅からの申請位置が確認されます）。
5. *学生証の撮影・提出*: 明るい場所で学生証（または在学証明書）の表・裏をカメラで撮影し、画像をアップロードします。
6. 申請理由（「授業で GitHub Copilot および Codespaces を利用するため」等）を簡潔に入力し、提出（Submit）します。

※ 申請の承認には数分〜数日かかる場合があります。初回授業に間に合わない場合でも、まずはアカウント作成と Organization 参加までを完了させておき、Codespaces の起動と Copilot 連携の確認は承認完了後（第2回授業まで）に行ってください。

** アカウント情報・GitHub URLの提出
教員およびTAが課題提出の確認や権限付与を行えるよう、自分の GitHub プロフィール URL を提出します。

*** 自分のプロフィール URL の確認
1. GitHub にログインした状態で、右上のアイコンをクリックし ~Your profile~ を選択します。
2. ブラウザのアドレスバーに表示されている URL（例: ~https://github.com/ユーザー名~ ）をコピーします。

※ 提出するのは **ユーザー名（半角英数字のID、例: ~swu-s1234567~）** です。プロフィールに設定した日本語の表示名（Display Name）やメールアドレスと混同しないよう注意してください。

*** シークレットブラウザによる動作確認
1. ブラウザのシークレットウィンドウ（プライベートモード）を新しく開きます。
2. コピーしたプロフィール URL を貼り付けてアクセスします。
3. **ログインしていない状態**で自身のプロフィールページが表示されるか確認します（設定画面の URL やダッシュボードの URL を誤ってコピーしていないか確認するため）。

*** 大学 LMS フォームへの提出
1. 学内 LMS（Moodle や UNIPA 等）に用意された「GitHub アカウント情報提出フォーム」を開きます。
2. 学籍番号、氏名、GitHub ユーザー名、および確認したプロフィール URL（ ~https://github.com/ユーザー名~ ）を入力して提出します。

** GitHub Organization に登録する
授業専用のリポジトリ配布・課題管理を行う「授業 Organization」に参加します。

*** 招待の受諾
1. 大学メール宛に届いている GitHub からの招待メール（件名: ~You've been invited to join...~）を確認します。
2. メール内の ~Join @[授業Organization名]~ ボタンをクリックします。
3. メールが見つからない場合は、直接ブラウザで以下の招待URLにアクセスします：
   - ~https://github.com/orgs/[授業Organization名]/invitation~
4. 画面上の ~Join [授業Organization名]~ をクリックして参加を完了させます。

*** 参加状態の確認
1. ~https://github.com/[授業Organization名]~ にアクセスします。
2. 授業 Organization のトップページが表示され、メンバーとして登録されていることを確認します。
