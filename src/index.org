* はじめに
本サイトは、2026年度後期に開講される「プログラミング中級（DI1A）」の授業資料・演習ガイド・課題提出情報を集約したポータルページです。
本授業では、Webアプリケーションのフロントエンド（画面構成・動的機能）を支える **HTML / CSS / JavaScript** の実践的な習得を目指します。

今年度の授業では、最新のAI支援開発ツール **GitHub Copilot** を活用し、AIと対話しながらコードを生成・理解・デバッグする **バイブコーディング（Vibe Coding）** の学習スタイルを取り入れます。

* 1. ガイダンス
** 学習目標
- **フロントエンド技術の理解と利用**: Webの仕組み（クライアント/サーバー通信）や画面構成要素を深く理解して活用できる。
- **マークアップ言語（HTML/CSS）の習得**: セマンティックなHTML構造と見やすく使いやすいデザイン・レイアウトを構築できる。
- **JavaScriptによる動的UIの実現**: イベント処理、DOM操作、非同期処理（fetch/async/await）を用いて動的なユーザー体験を実現できる。

** 目的・狙い
- **バイブコーディング（Vibe Coding）の導入**: 構文の暗記や単純なタイピングエラー（Syntax Error）による挫折を防ぎ、目的・設計の思考に集中する。
- **プロンプト思考（要求定義力）の育成**: AI（GitHub Copilot）に対し、構造・見た目（Vibe）・制約条件を明記した論理的指示を与える能力を養う。
- **コード解読力（Read & Verify）とデバッグ力**: AIが生成したコードの仕組みを解読し、F12デベロッパーツールとCopilot Chatを組み合わせた対話型デバッグで自力解決する姿勢を身につける。

* 2. GitHubアカウント作成とOrganization参加
** GitHub Educationのアカウントを作成
1. **GitHubアカウントの登録**: 大学発行のメールアドレス（`@...ac.jp`）を使用してアカウントを作成または追加認証する。
2. **GitHub Education（学割）申請**: 学生証画像を準備し、GitHub Student Developer Pack へ申請を行う（GitHub Copilot と Codespaces 月180時間が無料化）。

** アカウント、GitHub URLの提出
1. **プロフィール名・設定の確認**: 学割トラブルや個人識別不能を防ぐため、DisplayName に英語表記の本名（例: `Taro Yamada`）を設定する。
2. **プロフィールURLの提出**: `https://github.com/ユーザー名` をシークレットウィンドウで動作確認の上、授業指定フォームへ提出する。

** GitHub Organizationに登録
1. **招待の確認**: 大学メール宛の招待メール、または直接指定リンク（`https://github.com/orgs/[授業Organization名]/invitation`）を開く。
2. **Organizationへの参加**: `Join [授業Organization名]` をクリックし、授業用チームへの所属を完了させる。

👉 **[[file:github-account-and-org.org][GitHubアカウント作成とOrganization参加ガイドを開く]]**

* 3. リポジトリ作成とCodespace
** 教員がOrganizationで作成したテンプレートからリポジトリを作成
1. **テンプレートリポジトリの選択**: 授業Organizationページ（`https://github.com/[授業Organization名]`）から `lesson01-template` を開く。
2. **Privateリポジトリの生成**: `Use this template` ➔ `Create a new repository` を選択し、リポジトリ名 `lesson01-学籍番号`（Private設定）で作成する。

** GitHub codespaceを立ち上げる
1. **Codespacesの生成**: 作成した自分用リポジトリ画面で `<> Code` ➔ `Codespaces` タブ ➔ `Create codespace on main` をクリックする。
2. **画面レイアウトの整理**: 不要なエディタータブを閉じ（`Ctrl+W`）、`Ctrl+B` で左サイドバーを折りたたんで作業領域をすっきり確保する。

** バイブコーディングを試す
1. **Copilot Chatの起動**: 左アクティビティバーの吹き出しアイコン（GitHub Copilot Chat）を開く。
2. **プロンプト送信とコード反映**: 目的・構造・制約（HTMLのみ、CSSクラス追加等）を指定した指示を送信し、提案コードを `Apply in Editor` でファイルへ反映・動作確認する。

** 作業内容をコミット・プッシュ
1. **変更の確認とコミット**: VS Codeの「ソース管理」パネル（またはターミナル）から、意味のある単位でメッセージを入力してコミットを行う。
2. **GitHubへのプッシュ**: リポジトリの `main` ブランチへ変更をプッシュし、GitHub上のWeb画面で最新コードが反映されていることを確認する。
