* COMMENT バイブコーディング
** 概要
バイブコーディングとは何か、従来のプログラミング学習との違い、初学者が得られる学習効果、そして本授業における実践の進め方を解説します。

** バイブコーディング（Vibe Coding）とは
バイブコーディングとは、開発者が自分でコード行を記述する代わりに、生成AI（GitHub Copilot等）をコーディングパートナーとして対話し、プロンプトを入力してアプリを作成・変更する新しい開発アプローチです。
作りたい機能やデザインの雰囲気（Vibe）、目的を自然言語でAIに伝え、実際のコード記述処理をAIに委ねます。

** 従来のプログラミング学習との違い
従来のプログラミング教育では、文法（構文）の暗記やセミコロンの打ち忘れといった単純なエラーで初心者が挫折しがちでした。
バイブコーディングを取り入れることで、手打ちのストレスを減らし、「何を作るか（目的）」や「どのような構造か（設計）」という本質的な概念理解に集中できます。

** 初学者が得られる3つの学習効果
- 概念理解の優先 :: 文法エラーへの対処ではなく、全体のロジックやWeb構造の理解を優先できます。
- コード読解力（リバースエンジニアリング） :: AIが出したコードを実行し、デベロッパーツール等で解読することで、読み手（コードレビュアー）としての視点が育ちます。
- プロンプト思考（要求定義力） :: 曖昧な指示では意図通りに動かないことを体験し、AIに正確な条件・制約を与える論理的思考力が身につきます。

** 授業における実践の進め方
- スモールステップでの指示 :: HTMLでの骨格作成、CSSでの見た目の制御、JavaScriptでの動的機能の付加と、指示の粒度をコントロールしながら進めます。
- 対話型デバッグ :: AIが生成したコードのエラーや意図しない挙動に対し、AI自身に原因を尋ねて修正させるデバッグ体験を行います。

** GitHubアカウント・学割・提出関連トラブル
*** 大学メールアドレス（.ac.jp）の認証メールが届かない
- 原因 :: 大学メールアドレスの登録忘れ、または迷惑メールフォルダへの振り分け。
- 対処法 ::
  1. GitHub の ~Settings~ > ~Emails~ を開き、大学発行のアドレス（~@...ac.jp~）が ~Unverified~ になっていないか確認する。
  2. ~Resend verification email~ をクリックし、大学のWebメールシステムで迷惑メールフォルダを含めて確認する。

*** GitHub Education（学割）申請が却下される・位置情報エラーが出る
- 原因 :: プロフィール氏名がローマ字本名でない、カメラの位置情報権限がオフになっている、学生証の画像が鮮明でない。
- 対処法 ::
  1. ~Settings~ > ~Public profile~ の ~Name~ を英語表記の本名（例: ~Taro Yamada~）に変更する。
  2. スマホやPCのブラウザ設定で位置情報アクセス（GPS）を許可した上で、明るい場所で学生証を再撮影して申請する。

*** Organization の招待通知が届かない
- 原因 :: 登録メールアドレスの通知見落とし、または通知設定の遅延。
- 対処法 ::
  1. 招待メールを探す代わりに、ブラウザで直接 ~https://github.com/orgs/[授業Organization名]/invitation~ にアクセスする。
  2. 画面上に表示される ~Join [授業Organization名]~ ボタンをクリックして承認する。

*** 誤った提出URL（ダッシュボードや設定画面等）を送信してしまう
- 原因 :: ログイン状態の画面URLをそのままコピーしてしまう。
- 対処法 ::
  1. 自分のプロフィールURL（~https://github.com/ユーザー名~）をコピーしているか確認する。
  2. シークレットブラウザ（プライベートモード）でそのURLを開き、ログインなしで自身のプロフィールページが表示されるか検証する。

*** 2段階認証（2FA）のデバイス変更によるロックアウト
- 原因 :: スマホの機種変更やアプリ削除による認証コード消失。
- 対処法 ::
  1. 2FA設定時に保存したリカバリーコード（Recovery Codes）を使用してログインする。
  2. ログイン不能な場合は教員・管理者へ連絡し、アカウント設定の再セットアップを行う。

** GitHub Codespaces・開発環境関連トラブル

*** Codespaces が起動しない・フリーズする
- 原因 :: ブラウザのキャッシュ障害または一時的なコンテナ起動エラー。
- 対処法 ::
  1. ブラウザのページを再読み込み（F5 / Cmd+R）する。
  2. 改善しない場合は、VS Code左下の ~Codespaces~ アイコンまたはコマンドパレット（Ctrl+Shift+P）から ~Codespaces: Rebuild Container~ を実行する。

*** コマンド実行やファイル編集のアクセス許可プロンプトで停止する
- 原因 :: Copilot Cloud Agent や CLI がコマンド実行やファイル書き込みの承認を求めている。
- 対処法 ::
  1. VS Code や JetBrains IDE 上で表示される ~Allow~ （許可）または ~Allow for this session~ （このセッションで許可）をクリックする。
  2. ターミナル内で手動入力待ち（y/n 等）になっていないか確認する。

*** 必要なコンポーネント（Node.js等）不足によるエラー
- 原因 :: 環境依存ライブラリの未インストール。
- 対処法 ::
  1. Copilot Chat に対し「必要なコンポーネント（例: Node.js）をインストールするコマンドを実行してください」とプロンプトで指示する。

*** 画面がゴチャゴチャしていて見づらい / 作業領域が狭い
- 原因 :: 複数のエディタタブ、ファイルツリー（サイドバー）、ターミナルが同時に開いている。
- 対処法 ::
  1. 現在使っていないエディタタブを全て閉じる（ ~Ctrl+W~ / ~Cmd+W~ ）。*特にCopilotの精度低下や誤作動を防ぐためにも不要タブの削除が効果的です*。
  2. ~Ctrl + B~ で左サイドバー（エクスプローラー）を折りたたむ。
  3. ~Ctrl + @~ で下部ターミナルを隠す。
  4. ~Ctrl + K~ ➔ ~Z~ で Zen Mode（全画面集中モード）を起動する（ ~Esc~ 2回で解除）。

** バイブコーディング・Copilot Chat 関連トラブル

*** Copilot Chat の応答が途中でストップ・フリーズする
- 原因 :: LLMの出力生成タイムアウトや通信の瞬断。
- 対処法 ::
  1. チャットビュー下の ~Cancel~ ボタンを押し、以下のプロンプトを送信して再開させる。
     #+BEGIN_EXAMPLE
     Your previous response stalled. Try again, picking up from where you left off.
     #+END_EXAMPLE

*** 意図しないコードやデザインの崩れが出力される
- 原因 :: 曖昧なプロンプト（「良い感じにして」等）による仕様の解釈違い。
- 対処法 ::
  1. 目的・構造・色・制約条件を明記した具体的なプロンプトで再指示する。
  2. デザインの崩れがある場合は、画面のスクリーンショットを撮って Copilot Chat に添付し、「この部分の表示が崩れているので修正してください」と指示する。

*** 生成されたコードでエラーが発生する / ページが開かない
- 原因 :: 依存関係の欠落、構文ミス、またはサーバー未起動。
- 対処法 ::
  1. ブラウザのデベロッパーツール（F12）の ~Console~ タブを開き、赤文字のエラー文をコピーして Copilot Chat に貼り付け、「このエラーを解消してください」と指示する。
  2. プレビューリンクが表示されない場合は、「実装が完了しているか確認し、実行中のアプリケーションへのリンクを提示してください」と尋ねる。

*** 生成コードのセキュリティ・脆弱性リスク
- 原因 :: AIが生成したコードにセキュリティ上の不備が含まれる可能性。
- 対処法 ::
  1. F12 ツールや GitHub Education のセキュリティ機能を併用し、二段階認証の設定や定期的なコードレビュー（Read & Verify）を実施する。
  2. 入力データが教師データとして学習に利用されないよう、教育機関向けアカウント（GitHub Education / Business）の設定が適用されていることを確認する。
