* 授業概要
本サイトは、2026年度後期に開講される「プログラミング中級（DI1A）」の授業資料・演習ガイド・課題提出情報を集約したポータルページです。
本授業では、Webアプリケーションのフロントエンド（画面構成・動的機能）を支える **HTML / CSS / JavaScript** の実践的な習得を目指します。

今年度の授業では、最新のAI支援開発ツール **GitHub Copilot** を活用し、AIと対話しながらコードを生成・理解・デバッグする **バイブコーディング（Vibe Coding）** の学習スタイルを取り入れます。

* ガイダンスと授業計画
** 学習目標
- **フロントエンド技術の理解と利用**: Webの仕組み（クライアント/サーバー通信）や画面構成要素を深く理解して活用できる。
- **マークアップ言語（HTML/CSS）の習得**: セマンティックなHTML構造と見やすく使いやすいデザイン・レイアウトを構築できる。
- **JavaScriptによる動的UIの実現**: イベント処理、DOM操作、非同期処理（fetch/async/await）を用いて動的なユーザー体験を実現できる。

** 目的・狙い
- **バイブコーディング（Vibe Coding）の導入**: 構文の暗記や単純なタイピングエラー（Syntax Error）による挫折を防ぎ、目的・設計の思考に集中する。
- **プロンプト思考（要求定義力）の育成**: AI（GitHub Copilot）に対し、構造・見た目（Vibe）・制約条件を明記した論理的指示を与える能力を養う。
- **コード解読力（Read & Verify）とデバッグ力**: AIが生成したコードの仕組みを解読し、F12デベロッパーツールとCopilot Chatを組み合わせた対話型デバッグで自力解決する姿勢を身につける。
