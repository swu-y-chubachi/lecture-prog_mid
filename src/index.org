* 授業概要
** 本サイトについて
[[https://swu-y-chubachi.github.io/lecture-prog_mid/][本サイト]]は、2026年度後期に開講される「プログラミング中級（DI1A）」の授業資料・演習ガイド・課題提出情報を集約したポータルページです。
本授業では、Webアプリケーションのフロントエンド（画面構成・動的機能）を支える *HTML / CSS / JavaScript* の実践的な習得を目指します。

この授業では、最新のAI支援開発ツール *GitHub Copilot* を活用し、AIと対話しながらコードを生成・理解・デバッグする *バイブコーディング（Vibe Coding）* の学習スタイルを取り入れます。

** 学習目標
- *フロントエンド技術の理解と利用* ::
  Webの仕組み（クライアント/サーバー通信）や画面構成要素を深く理解して活用できる。
- *マークアップ言語（HTML/CSS）の習得* ::
  セマンティックなHTML構造と見やすく使いやすいデザイン・レイアウトを構築できる。
- *JavaScriptによる動的UIの実現* ::
  イベント処理、DOM操作、非同期処理（fetch/async/await）を用いて動的なユーザー体験を実現できる。

** 本授業の特徴
*** バイブコーディング（Vibe Coding）を積極的に取り入れる
バイブコーディングとは、開発者が自分でコード行を記述する代わりに、生成AI（GitHub Copilot等）をコーディングパートナーとして対話し、プロンプトを入力してアプリを作成・変更する新しい開発アプローチです。

作りたい機能やデザインの雰囲気（Vibe）、目的を自然言語でAIに伝え、実際のコード記述処理をAIに委ねます。

*** 従来のプログラミング学習との違い
従来のプログラミング教育では、文法（構文）の暗記やセミコロンの打ち忘れといった単純なエラーで初心者が挫折しがちでした。
バイブコーディングを取り入れることで、手打ちのストレスを減らし、「何を作るか（目的）」や「どのような構造か（設計）」という本質的な概念理解に集中できます。

*** 初学者が得られる3つの学習効果
- 概念理解の優先 ::
  文法エラーへの対処ではなく、全体のロジックやWeb構造の理解を優先できます。
- コード読解力（リバースエンジニアリング） ::
  AIが出したコードを実行し、デベロッパーツール等で解読することで、読み手（コードレビュアー）としての視点が育ちます。
- プロンプト思考（要求定義力） ::
  曖昧な指示では意図通りに動かないことを体験し、AIに正確な条件・制約を与える論理的思考力が身につきます。

*** 授業における実践の進め方
- スモールステップでの指示 ::
  HTMLでの骨格作成、CSSでの見た目の制御、JavaScriptでの動的機能の付加と、指示の粒度をコントロールしながら進めます。
- 対話型デバッグ ::
  AIが生成したコードのエラーや意図しない挙動に対し、AI自身に原因を尋ねて修正させるデバッグ体験を行います。

* 授業計画
** 【第1～2回】 GitHubとCodespace環境の構築
  1. GitHub アカウント作成と Organization への登録。
  2. GitHub Codespace と Copilot (AI) の利用法。

** 【第3回以降】 授業の流れの例（90分）
  1. *環境準備（10分）* ::
     テンプレートからのリポジトリ生成＆Codespaces起動。
  2. *教員デモ＆解説（30分）* ::
     ライブプロンプティングによる構造とコード解説。
  3. *個人演習（40分）* ::
     バイブコーディング演習、Copilotへの解説要求、対話型デバッグ。
  4. *まとめ＆Gitコミット（10分）* ::
     成果物のコミット・プッシュと振り返り。
