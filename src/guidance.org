* 学習目標（到達目標）
  本授業では、Webアプリケーションのフロントエンド（ユーザー画面）開発に関する基礎知識と実践スキルを身につけます。以下の3点を到達目標とします [70]。

  1. **フロントエンド技術の理解と利用** :: Webの仕組み、クライアント・サーバー間の通信、および画面構成要素を正しく理解し利用できる [70]。
  2. **マークアップ言語（HTML/CSS）の修得** :: 構造化されたHTMLとデザイン性の高いCSSを記述・調整し、見やすく使いやすいWeb画面を表現できる [70]。
  3. **JavaScriptによる動的UIの実現** :: イベント処理、DOM操作、および非同期処理（API連携等）を理解し、動きのあるインタラクティブなユーザーインタフェースを実現できる [70]。

* 授業の目的・狙い（バイブコーディングの導入）
  本授業では、AI（GitHub Copilot）と対話しながらコードを構築する **「バイブコーディング（Vibe Coding）」** を全面的に導入します [15, 58]。

  - **文法暗記からの脱却と概念理解の優先** ::
    セミコロンの脱落やタイピングミスなどの単純な構文エラーによる挫折を防ぎ、「どのような機能やデザインを作りたいか（目的）」という高次の設計思考に集中します [58]。
  - **プロンプト思考（要求定義力）の育成** ::
    AIに対して曖昧な指示（「良い感じにして」等）ではなく、目的・構造・デザイン・制約条件を論理的に指定する要求定義能力を養います [58, 60]。
  - **コード解読力（Read & Verify）の獲得** ::
    AIが生成したコードを単にコピペするのではなく、ブラウザのデベロッパーツール（F12）や Copilot Chat への解説要求を活用して「コードの仕組みや動く理由」を解読・検証するリバースエンジニアリング的な読解力を養います [58, 62]。
  - **対話型デバッグの体験** ::
    エラーが発生した際、F12コンソールのエラー文を AI に伝えて自力で原因特定と修正を行う、実践的なトラブル解決フローを修得します [61, 62]。
