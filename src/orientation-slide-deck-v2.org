* スライド1: 表紙・イントロダクション
  - タイトル :: プログラミング中級（DI1A）オリエンテーション
  - サブタイトル :: AI（GitHub Copilot）と対話し、Webアプリケーション開発をマスターする
  - 担当 :: デジタルイノベーション学科 中鉢 欣秀

* スライド2: 本授業の目的と到達目標
  - 概要 :: Webアプリケーションの「フロントエンド（ユーザー画面）」開発技術を実践的に習得する [70]。
  - 到達目標 1 :: フロントエンド技術およびクラウド開発環境（GitHub / Codespaces / Copilot）を理解し利用できる [70]。
  - 到達目標 2 :: マークアップ言語（HTML/CSS）を理解し、見やすい画面を表現できる [70]。
  - 到達目標 3 :: JavaScriptを理解し、動的なユーザーインタフェースを実現できる [70]。

* スライド3: 学ぶ技術とシラバス全体像（全15回）
  - GitHub環境構築（第1回） :: アカウント作成・Education学割申請・Org参加・Codespaces＆Copilot動作確認。
  - HTML（第2〜3回） :: Webページの骨格（タグ構造・フォーム・テーブル）の構築 [71]。
  - CSS（第4〜6回） :: デザイン・レイアウト（Flexbox・レスポンシブ・Bootstrap）の制御 [71]。
  - JavaScript（第7〜15回） :: 動的処理、制御構文、DOM操作、API連携・非同期処理（async/await） [71]。

* スライド4: 新しい学習手法「バイブコーディング（Vibe Coding）」
  - 従来の課題 :: 文法暗記やセミコロン脱落などの単純な構文エラーによる挫折 [58]。
  - バイブコーディングとは :: 作りたい目的や雰囲気（Vibe）をAIに伝え、実際のコード記述をCopilotに委ねる開発手法 [15, 58]。
  - 本授業での狙い ::
    - 手打ちのストレスを減らし、「目的・設計（プロンプト思考）」に集中する [58]。
    - AIが生成したコードを実行・解読する「読解力（Read & Verify）」を養う [58, 62]。

* スライド5: 受講環境（GitHub Education & Codespaces）
  - 環境構築トラブルゼロ :: ブラウザ上で動作する VS Code（GitHub Codespaces）を採用 [59]。
  - 学割特典 :: GitHub Student Developer Pack 登録により、Codespaces（月180時間無料）と GitHub Copilot が無料利用可能 [59]。
  - セキュリティとプライバシー :: 教育機関向けアカウントにより入力データの機械学習再利用を防ぎ、安全に利用可能 [81, 82]。

* スライド6: 毎回の90分授業モデルフロー
  - 1. 環境準備（15分） :: テンプレートから自分専用のリポジトリ作成＆Codespaces起動。
  - 2. 教員デモ＆解説（30分） :: ライブプロンプティング（Live Coding with AI）で構造やコードの仕組みを解説 [62]。
  - 3. 個人演習（35分） :: アレンジ（変奏曲）演習、Copilotへの解説要求、対話型デバッグの体験 [62]。
  - 4. まとめ＆Gitコミット（10分） :: 作業内容のコミット・プッシュとリフレクション。

* スライド7: 成績評価基準と評価ルーブリック
  - 評価割合 :: 授業参加・準備等 30% / 課題レポート・成果物 70% [72]。
  - 主な評価軸 ::
    - プロンプト思考（要求定義力）：目的・制約条件を整理したプロンプト作成。
    - コード解読力（Read & Verify）：生成されたコードの仕組みの説明能力。
    - 対話型デバッグ：F12デベロッパーツールの活用とCopilotを通じたエラー自力解決。
    - 成果物のクオリティ＆Git履歴管理。
