* 概要
本手順書は、「プログラミング中級」初回授業において、授業用 GitHub Organization への参加から、Codespaces の起動、GitHub Copilot の試用までの手順をまとめたガイドです。

* 前提条件
- GitHub アカウントの作成が完了していること。
- 大学のメールアドレス（~@...ac.jp~）で GitHub にログインできること。

* STEP 1: GitHub Organization への登録
** 1.1 招待の受諾
1. 大学メール宛てに届いている GitHub からの招待メール（件名: / You've been invited to join.../）を確認します。
2. メール内の *Join @[授業Organization名]* ボタンをクリックします。
3. もしくは、ブラウザで直接以下のアドレスにアクセスします：
   - ~https://github.com/orgs/[授業Organization名]/invitation~
4. *Join [授業Organization名]* を選択して参加を完了させます。

** 1.2 登録状態の確認
1. ~https://github.com/[授業Organization名]~ にアクセスし、Organization ページが表示されるか確認します。
2. メンバー一覧またはダッシュボードに自分のアカウントが反映されていることを確認します。

* STEP 2: Organization 内でのテンプレートリポジトリからの作成
** 2.1 テンプレートリポジトリの選択
1. 授業 Organization ページ（ ~https://github.com/[授業Organization名]~ ）を開きます。
2. 授業用テンプレートリポジトリ（例: ~lesson01-template~ ）をクリックします。

** 2.2 リポジトリの生成手順
1. ページ右上にある緑色の *Use this template* ボタンをクリックし、 *Create a new repository* を選択します。
2. 設定項目を以下のように入力します：
   | 項目 | 設定値 / 説明 |
   |------+----------------|
   | Owner | ~[授業Organization名]~ を選択 |
   | Repository name | ~lesson01-学籍番号~ （例: ~lesson01-s1234567~ ） |
   | Access level | *Private* （他の学生に見られないよう非公開に設定） |
3. *Create repository* ボタンをクリックします。

* STEP 3: GitHub Codespaces の立ち上げと基本的な使い方
** 3.1 Codespaces の起動
1. 作成した自分用のリポジトリ（ ~https://github.com/[授業Organization名]/lesson01-学籍番号~ ）を開きます。
2. 緑色の *<> Code* ボタンをクリックします。
3. *Codespaces* タブを選択します。
4. *Create codespace on main* をクリックします。
5. ブラウザ上で VS Code（GitHub Codespaces）が立ち上がるまで 1〜2 分待ちます。

** 3.2 Codespaces の基本操作
*** 画面構成の確認
- *左サイドバー*: ファイルエクスプローラー、検索、ソース管理、GitHub Copilot チャットアイコン
- *中央*: 編集エリア（ ~index.html~ など）
- *下部*: ターミナル（Terminal）

*** ターミナルの使い方
1. メニューバーの ~Terminal~ -> ~New Terminal~ を開きます。
2. 以下のコマンドを実行して、現在のディレクトリとファイル一覧を確認します：
   #+BEGIN_SRC bash
   pwd
   ls -la
   #+END_SRC

*** Web プレビューの起動確認
1. エクスプローラーで ~index.html~ を選択して開きます。
2. エディタ右上のプレビューアイコンまたは Live Preview 拡張機能等でブラウザ表示を確認します。

* STEP 4: GitHub Copilot を試す（バイブコーディングの第一歩）
** 4.1 Copilot Chat の起動
1. 左アクティビティバーにある *GitHub Copilot Chat* アイコン（吹き出しマーク）をクリックします。
2. チャットパネルが開くことを確認します。

** 4.2 コパイロットへの質問（コード解説の要求）
1. チャット入力欄に以下のプロンプトを入力して送信します：
   #+BEGIN_EXAMPLE
   このリポジトリに含まれている index.html の構造と役割を、プログラミング初心者向けにわかりやすく解説してください。
   #+END_EXAMPLE
2. Copilot から返答があるか確認し、解説内容を読み込みます。

** 4.3 バイブコーディング体験（コードの自動生成と反映）
1. Copilot Chat に次の指示（プロンプト）を出します：
   #+BEGIN_EXAMPLE
   index.html に、JavaScript を使った「ボタンを押すと表示メッセージが切り替わる機能」を追加するためのコードを作成してください。
   #+END_EXAMPLE
2. Copilot が提案したコードを確認します。
3. 提案コードの右上にある *Apply in Editor* （または *Insert at Cursor* ）ボタンをクリックしてファイルに反映させます。
4. ファイルを保存（ ~Ctrl+S~ / ~Cmd+S~ ）し、プレビュー画面でボタンの動作を試します。
